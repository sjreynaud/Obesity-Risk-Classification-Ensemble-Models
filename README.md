**Project Overview**

This project develops and evaluates multiple machine learning classification models to predict obesity risk categories based on individual health, lifestyle, and demographic characteristics. Using the Kaggle "Multi-Class Prediction of Obesity Risk" dataset, four supervised learning approaches were implemented and compared:

   - Decision Tree
   - Bagging Classifier
   - Random Forest
   - Gradient Boosting

The objective of the project is to identify the most effective model for predicting obesity risk while exploring the strengths of individual and ensemble learning techniques. Each model was trained, validated, evaluated, and submitted independently to Kaggle for performance comparison.

**Key Features**

   - Comprehensive data preprocessing and feature engineering
   - Multi-class classification of obesity risk levels
   - Four independent machine learning model implementations
   - Enhanced visualizations for model interpretation
   - Feature importance analysis
   - Confusion matrices and classification reports
   - Kaggle competition submissions for each model
   - Reproducible Jupyter Notebook workflow

**Project Objectives**

The primary goals of this project are to:

   1. Predict obesity risk categories using machine learning techniques.
   2. Compare the performance of Decision Tree and ensemble-based methods.
   3. Evaluate model accuracy using validation datasets and performance metrics.
   4. Interpret model behavior through feature importance and visualization techniques.
   5. Generate multiple Kaggle submissions and identify the highest-performing model.
